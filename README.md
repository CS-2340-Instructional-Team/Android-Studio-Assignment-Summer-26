# AndroidAssignmentSummer2026
In this assignment, you will be completing the implementation of a simple Food Bracket Tournament App by filling in 8 different TODOs representing missing parts of a fully functional app.

The app will have one Activity (BracketActivity) that allows the user to:
- Vote between two competing foods in a head-to-head matchup
- See feedback displaying which food they chose
- Navigate to the next button using a Next button
- Reset the bracket to enter again
- Track win counts for all 5 foods across 10 total matchups


The project folder contains 8 TODOs in 5 different files:

`BracketActivity.java` contains TODO 1, 3, 4, 6

`BracketManagerSingleton.java` contains TODO 2

`Matchup.java` contains TODO 5

`activity_bracket.xml` contains TODO 7

`ExampleUnitTest.java` contains TODO 8

Note: Some of the TODOs depend on earlier ones. We recommend doing them in sequential order.

Refer to the Android tutorial videos posted on Canvas for implementation tips.
